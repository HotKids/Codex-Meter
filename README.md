# Codex Meter

在 Android 上查看 Codex 剩余用量与重置时间。

Codex Meter 将 ChatGPT 账户的会话限额、每周限额和剩余额度集中显示在首页，也支持桌面小组件、用量提醒和实时通知，方便随时了解还能用多少、何时重置。

[下载最新版](https://github.com/HotKids/Codex-Meter/releases/latest) · [反馈问题](https://github.com/HotKids/Codex-Meter/issues) · [更新记录](CHANGELOG.md)

## 下载与安装

支持 **Android 11 及以上**。

在 [发布页面](https://github.com/HotKids/Codex-Meter/releases/latest) 下载 `.apk` 文件并安装。如果系统提示安装来源受限，请允许当前浏览器或文件管理器安装应用。

后续可在应用的「设置 → 应用更新」中检查新版本，也可从发布页面下载安装包更新。

## 开始使用

1. 打开应用，按引导登录 ChatGPT。也可稍后在设置页登录。
2. 在浏览器中完成 OpenAI 登录与授权，随后返回应用。无需填写 API Key 或手动复制令牌。
3. 登录后查看首页用量。通过首页编辑按钮选择要显示的项目，并拖动调整顺序。
4. 按需添加桌面小组件，或在设置中开启用量提醒和实时通知。

登录与刷新需要能够访问 OpenAI / ChatGPT 的网络。

## 主要功能

- **用量概览**：查看会话限额、每周限额及重置时间；账户采用月周期时，会显示对应的每月限额。
- **剩余额度**：查看购买额度的当前余额。
- **重置额度**：查看可用数量及到期时间；支持此功能的账户可在应用内使用重置额度。
- **用量历史**：查看本机记录的用量变化、消耗速度和预计耗尽时间。历史从应用成功刷新时开始积累，预计时间为估算结果。
- **用量提醒**：设置剩余用量预警、限额重置提醒，以及重置额度新增或到期提醒。
- **外观与迁移**：支持简体中文和英文、明暗主题、Android 12 及以上的系统动态取色，以及设置导入和导出。

可用的限额周期、剩余额度和重置额度取决于账户实际返回的数据。首页会自动隐藏没有可用余额或重置额度的项目。

## 桌面小组件

长按桌面，打开小组件列表，找到 **Codex Meter**，选择小组件并设置显示内容。

| 小组件 | 适合查看的内容 |
|---|---|
| **Codex 仪表盘 · 2×1** | 以圆弧显示会话用量、每周用量或重置倒计时，适合紧凑布局；宽度固定 |
| **Codex 用量 · 2×2 及以上** | 以卡片显示用量、重置时间和剩余额度，可调整尺寸及内容顺序 |

两种小组件的用量百分比均表示**剩余用量**。用量卡片还可显示可用重置额度，剩余额度则以数值显示。

Pro 套餐的新小组件默认显示每周用量和重置时间，会话限额可在自定义页面中开启。已保存的小组件选择会保留。

小组件支持背景和不透明度设置。用量卡片可通过刷新按钮更新数据，点击内容区域可打开应用。兼容的 Samsung One UI 设备还支持锁屏与息屏显示小组件。

## 实时通知与提醒

在「设置 → 实时通知」中启动实时监控，即可在通知中查看用量与重置信息，也可设置达到指定阈值时自动启动。通知中的显示项目与顺序跟随**最近一次保存的小组件设置**；首页隐藏会话限额时，通知也会隐藏该项。

实时活动、状态栏胶囊及 Samsung Now Bar 的显示取决于系统版本、固件和通知权限；其他设备可使用普通持续通知。用量提醒可在「设置 → 用量提醒」中单独配置。

## 隐私与数据

- 登录在 OpenAI 的浏览器页面中完成，应用不会获取账户密码。
- 登录凭证受 Android Keystore 保护，加密保存在本机；用量历史和设置也保存在本机。
- 登录与用量查询直接连接 OpenAI / ChatGPT，不经过本项目的中转服务器；应用更新通过 GitHub 完成。
- 备份迁移可选择包含登录信息。包含登录信息的导出文件含有账户令牌，请妥善保管。

更多信息可在应用的「隐私说明」中查看。
