# 项目检查与重构记录

本次检查覆盖全项目构建、静态检查、核心自测和手机端回归测试；重点核对手机小组件入口、配置持久化、升级恢复、设置导入、后台调度、通知、登录存储、更新安装与 CI。不是逐行形式化审计，也没有连接真实账号或手机。

## 已修复与重构

| 问题 | 修改后的行为 |
| --- | --- |
| 编辑页默认卡片，但直接添加和旧配置仍选择仪表盘/条形布局 | `WidgetOptions.defaults()` 统一默认卡片；`HomeWidgetPreferences` 集中配置读写和一次性迁移；编辑页不再另设默认值 |
| 更新同版本 APK 时可能跳过配置修复 | 小组件配置版本独立于应用版本，打开应用或覆盖安装后可触发修复 |
| 桌面选择器仍引用旧布局 | 初始布局和预览改用卡片，合并冗余 Android 9 资源文件、修正 Android 12 专用资源覆盖；增加静态占位文字及重新编辑能力 |
| 保存、导入或切换经典布局可绕过选择上限 | 在持久化边界统一规范化为一至两项，保留顺序与可选五小时限额 |
| 响应式小组件为每个尺寸重复读取凭据和缓存 | `QuotaCardState` 每次捕获一份缓存状态，各尺寸共用相同数据与时间 |
| 导入后续分区非法时，前面的设置已被修改 | 写入前校验全部选中分区、提醒时间和凭据完整性；未选中的分区不阻断导入 |
| 反编译遗留数字常量掩盖 API 含义 | 手机端视图可见性、字体、Intent、PendingIntent、闹钟、调度与加密参数改用对应命名常量 |
| 历史图表触摸结束缺少标准点击通知 | 补充 `performClick()`，结束拖动时恢复父级滚动拦截 |
| 更新频率英文转换受系统语言影响 | 使用固定 `Locale.ROOT` |
| CI 未执行 Android 界面回归测试，普通分支推送不触发检查 | main/alpha 推送运行核心及 Android 测试并保存报告；发布仍只由版本标签触发 |

`AppPreferences` 的小组件读写重复逻辑已移入 `HomeWidgetPreferences`；锁屏配置仍走独立路径。没有新框架、依赖升级或数据协议变更。

## 配置迁移规则

- 新组件默认“每周限额＋本机用量趋势”，五小时限额可在编辑页选择。
- 旧默认四项组合迁为“每周限额＋趋势”；自定义组合保留原顺序的前两个受支持项目，单项选择保持单项。
- 保留主题、颜色、透明度和百分号选择。趋势数据不足时显示积累状态，不生成假数据。
- 已保存的卡片选择保留；迁移只执行一次。后续方案已统一为自适应布局，只有 2×1 保留原方向盘（配置版本 2）。
- 所有桌面布局的两项上限都适用于编辑、保存及导入；旧经典布局的导入也无法绕过。
- 覆盖安装后打开应用可启动修复，无须删除组件或清空登录数据。
